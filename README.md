# Gerador de Documentos — Sala de Situação da Universidade de Brasília

Site estático para GitHub Pages.

## Publicação

1. Crie um repositório público.
2. Faça upload de `index.html` e `.nojekyll` diretamente na raiz do repositório.
3. Vá em Settings → Pages.
4. Em Build and deployment, selecione `Deploy from a branch`.
5. Branch: `main`.
6. Folder: `/(root)`.
7. Clique em Save.

O arquivo principal precisa se chamar exatamente `index.html`.
